# 챕터 2·3 확장 구현 계획

> 실행: 이 세션에서 순서대로 직접 진행한다 (superpowers:executing-plans). 단계는 체크박스로 표시한다.

**목표:** 설계 문서 `docs/superpowers/specs/2026-10-30-chapters-2-3-design.md`대로 챕터 2·3(페이즈 10개, 새 몬스터, 보스 2종, 미니보스 1종, 맵 테마 2종)을 추가한다.

**구조:**
- 새 몬스터의 행동은 챕터별 파일(`src/game/mobs/`)에 함수로 둔다. `Monster`는 `def.kind`로 행동 함수를 찾는다.
- 새 그림은 `assets-src/`에서 `public/assets2d/`로 복사해 로드한다. 색 변종은 부팅 때 다시 칠한다.
- 맵은 `buildLevel`이 테마별 세트(배경·바닥·발판·장식)를 고르도록 나눈다.

**기술:** Phaser 3.80, TypeScript, Vite. 이 저장소에는 단위 테스트가 없다. 확인 수단은 다음 세 가지다.
- `npx tsc --noEmit`, `npm run build`
- 개발 서버의 `window.__bw` 훅(start, spawn, battle, game)
- 스크린샷

## 전역 제약

- 그림은 GothicVania CC0 에셋만 쓴다 (`assets-src/` → `public/assets2d/`).
- 새 재료·무기·장비는 만들지 않는다. 보상은 기존 재료(`bone_shard`, `mana_crystal`, `wing_membrane`, `golem_core`, `elite_sigil`, `lord_heart`)만 쓴다.
- 기존 챕터 1 동작과 수치는 바꾸지 않는다.
- 주석과 화면 문구는 한국어로, 주변 코드 문체에 맞춘다.
- 커밋은 작업 단위로 하고, PR만 만든다 (머지는 사용자 허락 후).

### 작업 2: 데이터와 몬스터 연결 구조

**파일:** `src/data/monsters.ts`, `src/data/phases.ts`, `src/game/monster2d.ts`, `src/game/battleScene.ts`, `src/game/player2d.ts`

**만드는 것:**
- `MonsterKind`에 추가: `lantern_wraith | halo_wraith | fire_skull | hell_cat | blood_skeleton | frost_mage | fallen_angel | hell_hound | silver_wolf | flame_beast | wraith_knight | abyss_lord`. 수치는 설계 문서 표를 따른다.
- `PhaseDef`에 `chapter: number`, `dmgMul?: number`. `Theme`에 `'church' | 'castle'`.
- `Monster` 생성자 인자에 `dmgMul`을 추가해 `damage`에 곱한다.
- `Monster.ward`(남은 시간)와 `Monster.wardMul`. `hitMonster`에서 피해에 곱하고, 몬스터 위에 육각 이펙트를 띄운다.
- 행동 함수 연결: `type Behavior = (m: Monster, dt: number) => void`. `BEHAVIORS: Partial<Record<MonsterKind, Behavior>>`는 `mobs/chapter2.ts`·`chapter3.ts`가 내보낸다. `Monster.update`에서 기존 switch에 없는 kind는 `BEHAVIORS[kind]`를 부른다.
- 행동 함수가 쓰도록 공개: `scene`, `state`, `stateTime`, `attackTimer`, `step`, `pattern`, `hitDone`, `targetX`, `targetY`, `phase2`, `summonAt`, `play()`, `walk()`, `face()`, `toPlayer()`, `endPattern()`, `look`.
- `blood_skeleton`은 기존 walker 행동, `frost_mage`는 caster 행동, `wraith_knight`는 nightmare 행동을 재사용한다(switch에 추가).
- `spawnMonster`의 비행 판정은 `MONSTERS[kind].flying`으로, 보스 배치(`golem_lord`)는 `def.boss`로 일반화한다.
- 보스 등장 안내는 몬스터 이름으로 한다.
- 플레이어 둔화: `Player.slowTime`, `moveSpeed()`에 0.6을 곱한다. `spawnEnemyBolt`에 `opts?: { slow?: boolean; homing?: number; kind?: 'orb' | 'frost' | 'flame' | 'feather' }`를 추가한다.

- [ ] 1. 데이터 타입과 정의를 추가한다(아직 페이즈는 추가하지 않음, 기존 페이즈에 `chapter: 1`).
- [ ] 2. Monster 공개 멤버, ward, dmgMul, 행동 함수 연결을 넣는다.
- [ ] 3. battleScene의 스폰·안내·적 탄 옵션·둔화를 고친다.
- [ ] 4. `tsc`를 돌린다. 개발 서버에서 `__bw.spawn('blood_skeleton')`, `'frost_mage'`, `'wraith_knight'`를 소환해 그림과 행동을 확인한다.
- [ ] 5. 커밋한다.

### 작업 3: 챕터 2 몬스터 행동

**파일:** `src/game/mobs/chapter2.ts`

**만드는 것:** `lantern_wraith`, `halo_wraith`, `fire_skull`, `hell_cat`의 Behavior. 설계 문서의 행동 설명을 따른다.
- 등불 망령: 플레이어와 120~180px 거리, 높이 FLOOR_Y-90 근처를 떠돈다. 공격 쿨다운마다 유도 도깨비불(`homing` 1.5rad/s, 속도 110)을 쏜다. 맞으면 2초 쿨다운으로 연기와 함께 사라져 플레이어 반대편에 나타난다.
- 후광 망령: 천천히 떠돈다. 5초마다 반경 140px 안의 다른 몬스터에게 `ward` 4초를 건다(연출: 금빛 고리 + 대상마다 육각 이펙트).
- 불타는 해골: 높이 FLOOR_Y-110 근처를 떠돌다 경고 0.4초 뒤 플레이어 쪽으로 280px/s 돌진한다. 플레이어에 닿거나 땅에 닿으면 폭발(반경 50, 피해 damage)하고 죽는다.
- 지옥 고양이: 걷다가 거리 80~200에서 웅크림 0.45초 → 포물선 도약으로 플레이어 위치를 덮친다. 착지 때 근접 판정을 한다.

- [ ] 2. `tsc` → 개발 서버에서 하나씩 소환해 30초씩 관찰하고 스크린샷을 남긴다.
