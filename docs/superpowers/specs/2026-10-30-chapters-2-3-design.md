# 챕터 2·3 확장 설계

작성일: 2026-10-30 · 상태: 승인됨

## 목표

- 챕터 2(버려진 대성당)와 챕터 3(마왕성)에 페이즈 10개를 추가한다.
- 고유한 그림을 가진 새 몬스터와 색 변종, 보스 2종, 미니보스 1종을 추가한다.
- 새 재료·무기·장비 보상은 이번 범위에서 뺀다.
- 그림은 모두 이미 가지고 있는 GothicVania CC0 에셋(`assets-src/`)에서 가져와 `public/assets2d/`에 복사한다.

### 보스 패턴

**타락천사** (공중을 떠다닌다)
- 깃털 탄막: 부채꼴로 깃털 탄을 7~9발 쏜다.
- 돌진 베기: 화면 한쪽 끝으로 날아갔다가 경고선 뒤 반대쪽으로 가로지른다.
- 빛기둥: 플레이어 주변 3곳에 경고 뒤 빛기둥이 내리꽂힌다.
- 체력 60%·30%에서 등불 망령 2마리를 부른다.
- 체력 50% 아래는 2단계: 패턴 간격이 30% 짧아지고 빛기둥이 5곳으로 는다.

**심연의 군주** (악마 군주 패턴 확장)
- 기존 패턴: 화염 숨결, 불덩이 연사, 내려찍기 충격파.
- 불기둥 줄: 플레이어 쪽으로 차례로 솟는 불기둥 5개.
- 운석 비: 경고 뒤 운석 4개가 떨어진다.
- 체력 70%·40%에서 지옥견 3마리를 부른다.
- 체력 50% 아래는 격노: 이동과 패턴 간격이 빨라진다.

- 2-1은 1-5를 깨야 열리고, 3-1은 2-5를 깨야 열린다.
- 보스는 몬스터 정의의 체력·공격력을 그대로 쓴다 (`hpMul` 1, `dmgMul` 1).
- 클리어 보상은 챕터 2가 챕터 1의 약 1.8배, 챕터 3이 약 3배다. 재료는 기존 재료를 쓴다.
- 마을의 페이즈 게시판은 챕터별 제목으로 묶는다.

## 맵 테마

- `church`: 교회 배경 패널(창문·기둥·제단·가고일)을 이어 붙인 벽을 패럴랙스로 깔고, 교회 타일셋의 석재로 바닥과 발판을 그린다. 장식은 기둥(column)과 촛대.
- `castle`: 고성 내부 파노라마를 배경으로, 성 타일셋의 벽돌로 바닥과 발판을 그린다.
- `buildLevel`은 테마별로 배경·바닥·발판·장식 세트를 고르는 구조로 나눈다.

## 코드 구조

- `src/data/monsters.ts`: 새 몬스터 정의.
- `src/data/phases.ts`: 새 페이즈, `dmgMul`, `chapter`.
- `src/game/monster2d.ts`: 기존 몬스터 행동은 그대로 두고, 새 몬스터 행동은 `src/game/mobs/chapter2.ts`, `src/game/mobs/chapter3.ts`로 뺀다. Monster는 행동 함수가 쓸 수 있도록 필요한 상태를 공개한다.
- `src/game/assets2d.ts`: 새 시트 로드·애니메이션, 색 변종은 classSprites처럼 부팅 때 다시 칠한다.
- 플레이어 둔화(`slowTime`), 몬스터 보호막(`ward`)을 추가한다.

## 확인

- 타입 체크와 빌드가 통과해야 한다.
- 개발 서버에서 새 몬스터를 하나씩 소환해 행동과 그림을 스크린샷으로 확인한다.
- 각 페이즈를 개발자 모드로 끝까지 진행해 클리어 처리와 다음 페이즈 열림을 확인한다.
- 보스 패턴을 하나씩 확인한다.
