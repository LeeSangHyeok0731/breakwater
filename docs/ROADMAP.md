## 1. 작업 방식 (사용자와 정한 규칙)

- 사용자는 기획자, 코드는 Claude가 전부 쓴다. 대답은 한국어로, 편하게.
- 기능마다 **브랜치 → 커밋 → 푸시 → `gh pr create`** 까지는 묻지 않고 한다. **머지는 사용자가 "머지해"라고 할 때만** 한다.
- 보고할 때는 **확인한 것 / 확인 못 한 것**을 나눠 적는다. 내가 정한 해석·수치는 따로 밝힌다.
- 사용자가 정한 효과·컨셉(`[확정]`)은 바꾸기 전에 묻는다. `[초안]` 수치는 Claude가 조정해도 된다.
- 테스트용으로 연 브라우저 탭은 끝나면 닫는다 (about:blank 탭을 남기지 말 것).
- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. PR 본문 끝: `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.

### 브라우저 테스트 요령
- 개발 서버: `http://localhost:5173/`. 첫 화면에서 `.landing-start`를 누르면 마을로 들어간다.
- 개발 훅: `window.__bw` (`game`, `battle`, `start(phaseId)`, `legion`, `spawn`, `step`).
- 탭이 가려지면 프레임이 멈추므로 시간을 직접 돌린다: `g.loop.sleep()` 후 `g.step(T, 1000/60)` 반복, 트윈은 `b.tweens.getDelta = () => 1000/60`.
- 입력은 `b.keys.pressedSet.add('attack')`, 누르고 있기는 `b.keys.down.add('slot8')`.
- 세이브를 지키려면 시작 전에 `localStorage['breakwater-save']`를 `bw-test-backup`에 복사하고, 끝나면 비교·복구한 뒤 백업 키를 지운다.
- 테스트 스크립트에서 모듈을 `import('/src/...')`로 불러오면 예전 코드가 캐시돼 있을 수 있다. 수정 직후에는 `?fresh=${Date.now()}`를 붙인다.
- 수련장(마을 교관 옆 허수아비)의 스킬별 피해 표로 궁극기 위력을 재면 편하다.
- PowerShell에서 `R`은 Invoke-History 별칭이라 함수 이름으로 쓰면 안 된다. `"a"+"b"`를 함수 인자로 넘기면 뒤쪽이 사라지니 문자열은 미리 합쳐 둔다.

### 궁극기 (무기마다 3번째 궁극 스킬, id는 옛 세이브 때문에 그대로)

| 직업 | 궁극기 | 방식 |
|---|---|---|
| 검사 | 천공 섬광 (`sword_thousand_blades`) | 위 #47 |
| 도객 | 혈월 발도 (`dao_blood_moon`) | 키를 누르고 있으면 충전(최대 10초). 플레이어 옆 20칸 세로 게이지. k번째 칸은 3 + (k-1)/2타 추가 (20칸 150타), 한 타 피해 칸마다 +15% (힘 70% → 280%). 떼면 화면 안 모든 적에게 몰아침(3.2초 안). 충전 중 걷기·점프 가능, 구르기·공격 불가, 맞음 |
| 궁수 | 별사냥 (`bow_aurora`) | 6초 동안 같은 적을 맞힐수록 별이 1씩 더 늘어남 (1, 3, 6 …, 상한 없음). 끝나면 장식용 화살비 뒤 적마다 별 개수만큼의 피해를 담은 거대한 마법 화살 한 발 |
| 총잡이 | 황금 탄환 (`gun_dead_eye`) | 세상이 느려지고 8발, 줄어드는 조준 원 타이밍. PERFECT 3500%+도탄 둘 / GOOD 2000% / 놓침 1000%. GOOD마다 서브 총 1개, PERFECT마다 2개 → 이후 발마다 각 800%, 끝에 일제 사격 |
| 마법사 | 룬 아마겟돈 (`staff_armageddon`) | 머리 위 방향 룬을 맞게 누를 때마다 운석(n번째 룬 마력 300%×n). 룬 4·9·15개에서 마법진 단계↑(룬당 운석 최대 3). 불·얼음·번개 3개 묶음 → 불기둥 750%·얼음 감옥 600%(기절)·연쇄 번개 700% (× 단계). 틀리거나 한 룬 2초 넘기면 끝, 대폭발 (300% + 룬당 150%) × 단계 배수(최대 2.5) |

수련장에서 잰 대략의 총 피해 (개발 세이브 Lv 99): 룬 아마겟돈 15룬 약 238만, 혈월 발도 10초 약 161만, 황금 탄환 약 104만, 별사냥 19발 약 77만. 천공 섬광은 최대 마나에 따라 크게 달라진다.

구조: `BattleScene.ult` (매 프레임 tick, `lock` = 공격 막기, `still` = 이동 막기, `src` = 피해 출처), `lastCastSlot`, `hitHook`, `HitOpts.silent`, `hitMonster`가 들어간 피해를 돌려준다. 코드는 `src/game/ultimates.ts`.

### 직업 패시브 (`src/data/classPassives.ts`, `stats.totalStats`에 반영)
- 투기 순환(검·도): 힘의 N% → 마력. 사냥꾼의 직감(활·총): (민첩+힘)의 N% → 마력, 민첩의 N% → 힘. 마력 공명(지팡이): 마력의 N% → 힘·민첩.
- 레벨로 배움: Lv 10 / 30 / 50에 20% / 35% / 50%. 가장 높은 기본 스탯 계열 하나만 켜짐 (Claude가 정한 규칙).
- 총 숙련(모든 계열): 총을 쓸 때만 치명타 피해 +(가장 높은 스탯 × 비율)%, 치명타 확률 +비율의 10%.
- 남은 빈틈: 힘 캐릭터는 민첩을 얻지 않아 활이 가장 약하다 (사용자가 일단 그대로 두자고 함).

### 챕터 6~10과 용 (`src/game/dragon/`, `src/game/mobs/chapter6.ts`, `lateChapters.ts`)
- 용 리그: 목·꼬리 마디 사슬, 두 마디 날개, IK 다리. `makeDragonArt(scene, id, palette, plan, z, scale)`로 크기·색만 바꿔 재사용.
- 용 보스 공통 패턴(`dragonBoss`): 숨결·할퀴기·꼬리·급강하·탄 비·격노(소환+기둥). 속성 `EL_FIRE/FROST/STORM/SHADOW`.
- 배경 5종은 팔레트로 코드 생성 (`world.ts`의 `CAVES` 표).
- 챕터 3의 책 이름이 이미 '마왕성'이라 챕터 10 책은 '마왕성 깊은 곳'.

### 수련장 (`src/game/training.ts`)
- 마을 교관 옆 허수아비(x 1130) → 쓰러지지 않는 허수아비 하나, DPS 측정판과 스킬별 표.
- 시간차 피해의 출처를 지키려고 수련장에서만 씬 타이머·트윈 콜백을 감싸고, 나갈 때 되돌린다.
- 허수아비가 하나라 광역 피해는 한 대상 몫만 잡힌다.

- **모든 무기와 방어구를 들고 하는 레이드**를 생각하고 있다.
- 그 준비로 **주력이 아닌 무기로도 피해가 나와야 한다** → 직업 패시브(#49)와 궁극기 재작업(#50·#52)이 그 준비였다.

아직 정해지지 않은 것 (다음 대화에서 사용자에게 물어볼 것):
- 레이드 보스: 챕터 10의 마왕 벨제로스를 강화한 것인지, 새 보스인지. 들어가는 곳(전투 기지 포탈? 마왕성?)과 해금 조건.
- "모든 무기를 든다"의 방식: 무기 5종을 모두 장착해 Tab으로 돌리는지, 페이즈마다 무기가 강제로 바뀌는지, 기믹마다 특정 무기가 필요한지.
- 방어구: 세트 방어구 여러 벌을 바꿔 끼는 기믹인지.
- 보상(새 무기 등급·강화 한도 상향과 묶을지), 하루 횟수, 난이도 단계.

설계 전 반드시 확인할 것: 사용자가 "마왕성 만들기"라고 했는데 챕터 10 '마왕성 깊은 곳'은 이미 있다. 레이드용 새 마왕성 맵을 말하는 것인지 먼저 물어본다.

### 4.2 남은 결정·과제
- **장비 성장 한계**: 무기가 전설 +10에서 끝나서 챕터 6부터는 레벨·세트 방어구로만 강해진다. 후반 챕터(특히 8~10)가 버거울 수 있다 → 새 무기 등급 또는 강화 한도 상향을 정해야 한다 (레이드 보상과 묶기 좋음).
- **혈월 발도 성능**: 화면 안 적이 43마리일 때 10초 충전 발도 → 평균 한 프레임 14ms, 순간 최대 356ms (150타 × 적 수만큼 피해 숫자). 사용자가 "그대로 둬"라고 해서 손대지 않았다. 필요하면 별사냥처럼 `silent` 타격 + 묶은 숫자로 바꾼다.
- 세트 방어구 획득·방어구 강화 방식은 사용자가 나중에 정하기로 했다 (지금은 개발 패널과 조각 상인).
- 군단장 확장은 보류 중. 챕터 보스 리그 리메이크, 배경 음악, 챕터 11 이후는 손대지 않았다.

### 4.3 아직 직접 확인하지 못한 것 (사용자 플레이 필요)
- **#56~#59 연출 전반의 실제 속도 손맛** (모두 고정 프레임 캡처로만 확인). 특히: 검·도 사거리 증가가 난이도에 주는 영향, 직업 궁극기 5종과 챕터 보스·용(공용 이펙트가 바뀌어 모양이 달라짐), 엘프 패링 성공·그로기 연출, 군단장 2단계·하드, 몬스터 수십 마리일 때 성능.
- **마왕 아스타로트 (#59)**: 패턴 난이도·예고 길이·피해 배율 [초안], 하드 난이도, 6분 끝까지 한 판, 그림자 분신이 맵 끝(카메라 밖)에서 나오는 것. 처음 봉인을 깰 때 한 번 27ms 프레임(다시 재면 14ms, 원인 미확인).
- 챕터 6~10 전반의 실제 속도 난이도와 손맛 (보스 체력 6권 약 3만 ~ 10권 약 7.8만), 권장 전투력이 레벨 성장과 맞는지, 이야기책 7~10권 화면.
- 궁극기 네 개의 실제 손맛: 황금 탄환 PERFECT 구간(0.2초), 룬 입력 2초 제한, 혈월 발도 충전 중 피격.
- 랜딩 화면·튜토리얼(#39·#40)의 실제 속도 확인 (예전부터 사용자 확인 대기).
