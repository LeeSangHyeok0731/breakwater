## 3. 스탯

### 3.1 기본 스탯

| 스탯       | 효과                                                              |
| ---------- | ----------------------------------------------------------------- |
| 힘 (STR)   | 근접 무기(도·검) 피해 증가. 활 피해에 30% 반영                    |
| 민첩 (DEX) | 원거리 무기(활) 피해 증가(70% 반영). 이동속도 증가(**상한 있음**) |
| 마력 (INT) | 최대 마나 증가. 마법 피해 증가                                    |
| HP         | 최대 체력 증가                                                    |

- **[확정]** 방어력 스탯은 없다. 생존은 회피·가드·패링 같은 조작과 HP로 해결한다.
- **[확정]** 스탯으로 늘어나는 이동속도에는 상한이 있고, 스킬·마법·장비 효과로 늘어나는 이동속도에는 상한이 없다.
- **[확정]** 치명타 시스템을 도입한다. 자세한 내용은 3.5 참고.

### 3.2 파생 수치 공식 [초안]

| 수치           | 공식                                                                       |
| -------------- | -------------------------------------------------------------------------- |
| 최대 HP        | 100 + HP × 10                                                              |
| 최대 마나      | 50 + 마력 × 5                                                              |
| 마나 자연 회복 | 초당 2 + 마력 × 0.05                                                       |
| 이동속도       | 기본 5 m/s × (1 + min(민첩 × 0.5%, **50%**) + 스킬·장비 보너스(상한 없음)) |

### 3.3 마나 회복 수단 [확정]

1. 시간에 따른 자연 회복
2. 기본 공격 적중 시 회복 **[초안: 적중 1회당 +2]**
3. 몬스터 처치 시 회복 또는 마나 구슬 드롭 **[초안: 일반 +3 / 엘리트 +15]**

### 3.4 근접 유저의 마나 문제 [확정]

힘이 주 스탯인 유저가 마나 때문에 마력에 포인트를 찍지 않아도 되도록, **공용 패시브 트리에 스탯 전환 패시브를 둔다.**

- 예: "힘의 N%만큼 마력이 추가로 증가한다" **[초안]** 전환된 마력은 최대 마나와 마나 회복에만 적용하고 마법 피해에는 반영하지 않는다. 공용 패시브 목록은 `src/data/passives.ts`.

### 3.5 치명타 [확정]

| 항목 | 내용 |
|---|---|
| 치명타 확률 | 주로 **무기**에서 얻는다. 일부 스킬에 치명타 확률 보정이 붙어 있다 |
| 치명타 데미지 | 기본 200%. 치명타가 터지면 원래 피해에서 200%가 **추가로** 증가한다 (원래 피해 100 → 300, 최종 ×3). 스킬로 추가 보정 가능 |
| 총 (예외) | **치명타가 터지지 않는다.** 대신 치명타 확률만큼 치명타 데미지가 늘고, 그 치명타 데미지의 80%만큼 최종 피해가 **항상** 증가한다 |

- **[확정] 총의 밸런스 의도**: 총은 초반에 매우 강한 무기다. 스탯 성장이 없어서 후반으로 갈수록 스탯을 받는 다른 무기에 피해량이 밀리도록 설계한다.

## 4. 무기와 직업

**[확정]** 무기 종류가 곧 직업이다: 검 → 검사, 도 → 도객, 활 → 궁수, 총 → 총잡이, 스태프 → 마법사. (2026-10-30 개편: 무기 교체 → 직업 교체)

**[확정]** 무기(직업) 2개를 장착하고 전투 중에 즉시 바꿀 수 있다. 교체하면 캐릭터 그림이 그 직업의 모습으로 바뀐다. 무기마다 스킬·마법 슬롯이 8개씩 있고, 교체하면 슬롯 세트도 같이 바뀐다.

- 직업 그림은 주인공 도트를 직업별로 다시 칠해 만든다 (망토·갑옷 색, 머리 소품). 원거리 직업은 평소 무기를 등에 메고, 쏘거나 겨눌 때만 손에 든다.

### 4.1 무기별 특성

| 무기   | 분류   | 스탯 영향         | 기본 공격 (좌클릭)            | 강화 공격 (우클릭) **[초안]**              | 특이사항                                                                                                                                                                                         |
| ------ | ------ | ----------------- | ----------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 총     | 원거리 | **없음**          | 사격 (높은 정확도, 높은 피해) | 정조준: 탄 퍼짐 감소, 피해 증가, 이동 감소 | 탄창 + 재장전. 성장은 강화와 상위 총으로만. 치명타 대신 고정 피해 증가 (3.5 참고) |
| 도     | 근접   | 힘 100%           | 세로 베기 → 횡 베기 콤보      | 크게 휘두르는 횡 베기 (넓은 범위, 차징)    | 외날. 검보다 피해가 높음                                                                                                                                                                         |
| 검     | 근접   | 힘 100%           | 세로 베기 → 횡 베기 콤보      | **찌르기**: 직선 관통 범위 공격            | 양날. 도보다 피해가 낮음                                                                                                                                                                         |
| 활     | 원거리 | 민첩 70% + 힘 30% | 사격 (한 발마다 자동 장전)    | 차징 사격: 오래 당길수록 피해·관통 증가    | 발사 후 장전 시간 있음                                                                                                                                                                           |
| 스태프 | 원거리 | 마력 100%         | 마나볼                        | 차징 마나볼                                | **마법은 스태프로만 사용 가능**                                                                                                                                                                  |

### 4.1.1 무기 목록 (2026-10-30 기준 20종)

| 종류 | 일반 | 희귀 | 영웅 | 전설 |
|---|---|---|---|---|
| 검 | 수련용 장검 | 강철 장검 | 군주의 화염검 | 성검 아스칼론 |
| 도 | 수련용 도 | 월광도 | 혈월도 | 뇌명도 |
| 활 | 사냥꾼의 활 | 바람의 장궁 | 세라핌의 깃활 | 심연궁 |
| 총 | 낡은 리볼버 | 사냥용 장총 | 마도 소총 | 용의 포효 |
| 스태프 | 견습 마법사의 지팡이 | 룬 지팡이 | 용암 심장 지팡이 | 심연의 홀 |

- 영웅 무기(혈월도·세라핌의 깃활·마도 소총)는 챕터 2 재료 **타락천사의 깃털**, 전설 무기는 챕터 3 재료 **심연의 파편**으로 교환한다.
- 무기마다 손에 든 그림·UI 아이콘·잔상 색·기운이 다르다.

### 4.2 피해 공식 [초안]

```
기본 피해 = 무기 공격력 × 강화 배율 × (1 + 스탯 반영치 / 100)
최종 피해 = 기본 피해 × 동작 계수 × 버프 배율 × 치명타 배율
```

- 치명타 배율 (총 외): 치명타가 터지면 `1 + 치명타 데미지`, 아니면 1
- 치명타 배율 (총): 항상 `1 + (치명타 데미지 + 치명타 확률) × 0.8`
  - 예: 치명타 확률 30%, 치명타 데미지 200% → 총은 매 발 `1 + 2.3 × 0.8 = ×2.84`
  - 같은 조건에서 다른 무기의 평균 배율은 `1 + 0.3 × 2.0 = ×1.6`
  - 총이 강한 것은 의도된 설계다. 후반 역전은 다른 무기의 스탯 성장(스탯 반영치)으로 만든다. 총의 무기 공격력과 강화 배율은 이 곡선에 맞춰 조정한다. **[초안]**

| 무기   | 스탯 반영치           |
| ------ | --------------------- |
| 총     | 0                     |
| 도·검  | 힘                    |
| 활     | 민첩 × 0.7 + 힘 × 0.3 |
| 스태프 | 마력                  |

- 동작 계수 예: 검 세로 베기 1.0, 횡 베기 0.9, 찌르기 1.3 / 도 세로 베기 1.2, 횡 베기 1.1, 강화 횡 베기 2.0
- 스킬·마법은 고유 공식을 따른다. 예: "힘의 400% 검기", "민첩 100% + 힘 100% 마력 화살"
  → `스킬 피해 = Σ(스탯 × 계수) × 무기 강화 배율 × 버프 배율`
- **[확정]** 강화 배율: +1당 ×1.08 (총은 스탯 성장이 없으므로 +1당 ×1.15로 더 크게)

### 4.3 비행 몬스터 대응 [확정]

- 근접 무기의 기본 공격(지상)은 공중의 적에게 닿지 않는다.
- 근접 유저는 **점프 공격**이나 **대공 스킬**로 비행 몬스터를 공격한다.
  - 근접 무기에는 땅에 선 채로 공중의 적을 칠 수 있는 대공 스킬이 있다.
- 원거리 무기는 그대로 조준해서 맞힐 수 있다.

## 5. 스킬과 마법

### 5.1 구조 [확정]

- **무기별 스킬 트리**: 총 / 도 / 검 / 활 / 스태프 각각 따로
- **공용 패시브 트리**: 스탯 전환, 마나 회복, 이동속도 같은 공통 효과
- 스킬 포인트는 레벨업으로 얻고, 트리에 자유롭게 나눠 투자한다.
- 스킬마다 마나 소모량과 쿨타임이 따로 있다. 위력이 강할수록 마나를 많이 쓴다.

### 5.2 스킬 (무기 전용 기술)

| 유형 | 예시                                                    |
| ---- | ------------------------------------------------------- |
| 버프 | 공격력 증가, 공격 속도 증가, 체력 증가                  |
| 공격 | 검: 힘의 400% 피해를 주는 검기 12개를 전방으로 발사     |
| 공격 | 활: 민첩 100% + 힘 100% 피해를 주는 마력 화살 12개 발사 |
| 대공 | 근접 무기용 올려베기·도약 공격 (비행 몬스터 대응)       |

**[확정] 스킬 설계 원칙**

- 구체적인 스킬 목록은 AI가 무기 특징에 맞게 자율적으로 설계한다.
- 트리 뒤쪽으로 갈수록 더 화려하고 강력해진다.
- 군중 제어(CC)와 디버프를 포함한다: 기절, 받는 피해 증가(6.4 참고), 공격력 감소, 이동속도 감소 등

### 5.3 마법 (스태프 전용)

| 유형           | 예시           |
| -------------- | -------------- |
| 기본 공격      | 마나볼         |
| 버프           | 데미지 증가 등 |
| 광역 공격      | 메테오         |
| 관통/지속 공격 | 레이저 커팅    |

- 대부분 마력의 영향을 받지만, 마법마다 반영 스탯과 계수가 다를 수 있다.

**[확정] 마법 설계 원칙**

- 구체적인 마법 목록은 AI가 자율적으로 설계한다. 뒤로 갈수록 더 화려하고 강력해진다.
- 군중 제어(CC)와 디버프: 기절, 받는 피해 증가, 공격력 감소, 이동속도 감소 등
- 지속 피해: 장판(바닥 지속 피해 지대) 같은 다양한 기믹
- 스태프 유저는 근접 공격에 약하므로 방어 마법을 둔다.

| 방어 마법 | 동작 |
|---|---|
| 방어막 (횟수형) | 정해진 횟수만큼 피격을 막는다. 맞을 때마다 1씩 깎이고 0이 되면 사라진다 |
| 보호막 (흡수형) | 정해진 피해량만큼 흡수한다. 흡수량을 다 쓰면 사라진다 |

### 5.4 상급·궁극 스킬과 스킬 세트 (2026-10-30 추가)

- 스킬에 등급이 있다: 일반 / **상급** / **궁극**. 등급이 높을수록 범위가 넓고(화면 안 모든 적) 연출이 화려하며, 마나·쿨타임·요구 레벨이 높다.
- 무기마다 상급 2개, 궁극 1개:

| 무기 | 상급 | 상급 | 궁극 |
|---|---|---|---|
| 검 | 천공 일섬 (화면 가로 참격) | 십자 심판 (화면 X자 참격 2회) | 만검귀종 (영검 30자루 낙하) |
| 도 | 월하 폭풍참 (거대 초승달 참격 6발) | 천붕 (내려찍어 화면 전체 땅 균열) | 혈월 강림 (화면 안 모든 적에게 8연속 참격) |
| 활 | 천궁 산개 (위로 쏜 화살이 30발로 갈라져 낙하) | 유성 화살 (강한 적 셋 유도 폭발) | 오로라 폭우 (3초 화살 폭우) |
| 총 | 도탄 난사 (적 사이를 튕기는 탄환) | 포격 요청 (적마다 포탄 낙하) | 데드아이 (모든 적 조준 후 일제 사격) |
| 스태프 | 연쇄 번개 (최대 10마리) | 블리자드 (4초 눈보라·둔화) | 아마겟돈 (운석 비 + 대폭발) |

- **스킬 세트**: 무기마다 슬롯(Q W E A S D F G)이 8칸이다. 배운 스킬이 8개를 넘으면 훈련관의 스킬 탭에서 세트에 넣을 스킬과 순서를 고른다. 고르지 않으면 배운 스킬을 목록 순서대로 채운다.

### 6.4 받는 피해 증가 디버프 [확정]

- 몬스터에게도 방어력 수치는 없다. 단단한 몬스터(골렘 등)는 HP로 표현한다.
- "방어력 감소" 대신 **받는 피해 증가** 디버프를 쓴다: 디버프가 걸린 몬스터는 피해를 N% 더 받는다.
- 여러 디버프가 겹칠 때 합산할지 곱할지, 상한을 둘지는 AI가 설계한다.

## 7. 페이즈 (스테이지)

### 7.1 구성 [초안]

```
챕터 1 · 버려진 묘지
 ├─ 1-1 버려진 묘지 외곽   일반 (5웨이브)
 ├─ 1-2 무너진 예배당      일반 (4웨이브, 마지막에 악몽마)
 ├─ 1-3 끝없는 밤          특별: 90초 생존
 ├─ 1-4 망자의 행렬        특별: 60마리 처치
 └─ 1-5 악마 군주의 제단   보스
챕터 2 · 버려진 대성당 (1-5 클리어 후)
 ├─ 2-1 대성당 회랑        일반 (5웨이브)
 ├─ 2-2 무너진 제단        일반 (4웨이브, 마지막에 악몽마)
 ├─ 2-3 촛불이 꺼지는 밤   특별: 100초 생존
 ├─ 2-4 망령의 성가        특별: 70마리 처치
 └─ 2-5 타락천사의 성소    보스
챕터 3 · 마왕성 (2-5 클리어 후)
 ├─ 3-1 마왕성 성문        일반 (5웨이브)
 ├─ 3-2 망령 기사의 회랑   일반 (4웨이브, 마지막에 망령 기사)
 ├─ 3-3 지옥견 사냥터      특별: 110초 생존
 ├─ 3-4 불타는 성채        특별: 80마리 처치
 └─ 3-5 심연의 옥좌        보스
```

- 챕터가 오를수록 몬스터 체력·공격력 배율이 오른다 (챕터 2: 약 ×1.6·×1.4, 챕터 3: 약 ×2.5·×1.9). 보상도 챕터 2가 챕터 1의 약 1.8배, 챕터 3이 약 3배.

- 페이즈마다 경기장 분위기(낮·노을·밤·용암·대성당·마왕성)가 다르다.
- 특별 스테이지는 웨이브 대신 몬스터가 계속 몰려오고, 시간이 지날수록 더 빨리 나온다.

### 7.2 일반 페이즈 [확정]

- 정해진 웨이브(**[초안]** 5웨이브)를 **전부 처치하면 클리어**한다.
- 등장: 일반 몬스터 + 중간 몬스터(엘리트·미니보스)
- 웨이브 사이에 짧은 휴식이 있다. **[초안: 5초]**

### 7.3 특별 스테이지 [확정]

일반 페이즈 사이에 섞여 나오는 미션형 스테이지.

| 미션      | 클리어 조건             |
| --------- | ----------------------- |
| 버티기    | 제한 시간 동안 살아남기 |
| 처치 목표 | 목표 처치 수 달성       |

### 7.4 보스 페이즈 [확정]

- 보스가 중심이 되는 넓은 스테이지. 보스를 처치하면 클리어한다.

### 7.5 실패 [확정]

- HP가 0이 되면 페이즈 실패.
- **그 판에서 얻은 골드·경험치·재료를 전부 잃는다.**

### 7.6 재도전과 소탕 [확정]

- 클리어한 페이즈는 언제든 다시 도전할 수 있다.
- **소탕**: 전투를 짧게 끝내고 해당 페이즈 보상의 일부를 받는다.
  - **소탕권**을 1장 쓴다.
  - 소탕권은 페이즈 클리어 보상으로 받거나 마을에서 골드로 산다.
  - **[초안]** 소탕 보상 = 일반 클리어 보상의 30%

## 8. 성장

### 8.1 경험치와 레벨업 [초안]

- 필요 경험치: `100 × 1.15^(레벨 - 1)`
- 레벨업 시:
  - 모든 기본 스탯 +1 (자동)
  - 스탯 포인트 +5
  - 스킬 포인트 +1

### 8.2 초기화 [확정]

- 스탯 포인트와 스킬 포인트는 초기화할 수 있고, 투자한 포인트를 전부 돌려받는다.
- 비용은 골드이고 레벨에 비례한다. **[초안]** `레벨 × 100 골드`
- 레벨업으로 자동 상승한 스탯은 초기화 대상이 아니다.

## 9. 마을과 경제

**[초안]** 마을은 직접 걸어 다니는 3D 공간이다. 대상에 다가가 상호작용 키(기본 F)로 창을 연다.

| 대상 | 기능 |
|---|---|
| 출정 게시판 | 페이즈 선택, 소탕 |
| 대장장이 브론 | 무기 강화, 재료 교환 |
| 잡화상 리나 | 무기·방어구·장신구·포션·소탕권 구매 |
| 교관 메이린 | 스탯 분배, 스킬·패시브 |
| 장비함 | 무기 2개와 방어구·장신구 장착 |
| Esc 메뉴 | 설정, 세이브 |


### 9.1 상점 [확정]

| 분류   | 내용                                                         |
| ------ | ------------------------------------------------------------ |
| 무기   | 총·도·검·활·스태프. 등급별로 여러 종                         |
| 방어구 | HP·스탯 보너스 위주 (방어력 스탯 없음). 부위: 머리, 상반신, 하의, 신발 |
| 장신구 | 반지·목걸이. 특수 효과 (마나 회복 증가, 이동속도, 치명타 등)  |
| 소모품 | HP 포션, 마나 포션, 소탕권 (버프 아이템은 추후)               |

- **[초안]** 방어구·장신구 목록은 `src/data/gear.ts`. 일반 등급은 골드로 사고, 희귀 이상은 재료 교환으로 얻는다.
- **[초안]** 체력 포션은 최대 HP의 35%, 마나 포션은 마나 60을 회복한다. 기본 키 Z·X. 한 페이즈에 종류마다 5개까지 쓸 수 있고, 페이즈에 실패해도 쓴 포션은 돌아오지 않는다.
- 장신구의 이동속도 효과는 스킬·패시브와 같이 상한이 없다.

### 9.2 장비 등급 [확정]

일반 → 희귀 → 영웅 → 전설. 등급이 높을수록 기본 공격력과 보너스(치명타 확률 등)가 높다. 등급별 수치는 AI가 설계한다.

### 9.3 무기 강화 [확정]

- **무조건 성공**한다. 골드와 재료를 소모한다.
- 단계가 오를수록 비용이 커진다. 최대 +10. **[초안]**

### 9.4 재료와 교환 [확정]

- 특정 몬스터가 특정 확률로 재료 아이템을 떨어뜨린다.
- 재료는 무기 강화에 쓰거나, 모아서 강력한 무기로 교환한다.
- 재료 종류, 드롭 테이블, 교환 레시피 **[미정]**

### 9.5 보상

| 출처          | 보상                           |
| ------------- | ------------------------------ |
| 몬스터 처치   | 골드, 경험치, 확률 재료 드롭   |
| 페이즈 클리어 | 클리어 보상(골드·재료), 소탕권 |
| 소탕          | 클리어 보상의 일부             |

## 12. 개발 단계

### MVP (1차 목표)

전투 손맛 검증에 집중한다.

- 플레이어: 이동, 카메라, 점프, 구르기, 가드/패링
- 무기: **검, 스태프** (2개 장착 및 교체)
- 스킬/마법: 무기당 2~3개 (검기, 대공 스킬, 메테오 등)
- 몬스터: 기본 4종 + 엘리트 1종
- 페이즈: 일반 페이즈 1개 + 보스 페이즈 1개
- 마을: 강화 화면, 스탯 분배 화면
- 저장: 자동 저장

### 이후 확장

1. 무기 추가: 도, 활, 총
2. 스킬 트리 UI 및 공용 패시브
3. 상점 (방어구, 장신구, 소모품)
4. 특별 스테이지, 미니보스
5. 소탕, 재료 교환
6. 파생 몬스터, 챕터 확장
7. 설정(키 변경), 세이브 내보내기

## 13. 미정 사항 목록

- [x] 치명타 시스템 → 3.5
- [x] 방어구 부위 → 머리, 상반신, 하의, 신발 (9.1)
- [x] 장비 등급 → 일반/희귀/영웅/전설 (9.2)
- [x] 치명타 데미지 → 원래 피해 +200% (최종 ×3) (3.5)
- [x] 총 치명타 공식 → 원안 유지, 초반 강세·후반 약세 의도 (3.5, 4.2)
